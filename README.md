# Persian-Author-Identification-by-LLMs
A freelance project to classify Persian texts by author using LLMs like ParsBERT and ParsGPT2.

🎯 Objective

Identify authors of Persian texts using large language models

Compare performance of different models on a self-collected dataset

⚙️ Tools & Technologies

Python 3

ParsBERT, ParsGPT2

📊 Results & Reflection

Successfully classified Persian text files

Explored strengths and limitations of modern LLMs in Persian NLP
